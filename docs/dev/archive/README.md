# docs/dev/archive/ — 归档层

已否决的架构片段与错误交接稿的**只读归档**。归档 ≠ 删除：保留原文与错误原因，
供后续 Agent 不再重蹈，也便于追溯「为什么最终方案长这样」。

规则：

1. 归档文件编号 `NNNN-主题.md` 顺延，只读，不再修订。
2. 每篇归档必须写明三件事：**错在哪**、**为什么错**、**被什么取代**（指针）。
3. 现行方案一律以 `engineering/ADR-*` 与 `architecture/` 为准；归档内容不得被
   当前任何代码或文档引用为依据。
4. baseline（冻结原稿）不是归档——那是设计历史，归档是错误历史。
